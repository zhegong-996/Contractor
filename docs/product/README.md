## 一句话定位

**SuitMe 是一台跑在你自己电脑上的「AI 员工协作台」**：一群 Agent 像同事一样接活、干活、互相交接，遇到需要人拍板的事就来问你，干完的活按证据验收，沉淀的经验回流成组织记忆。数据在本机、模型凭据自己管、验收权永远在人手里。

## 解决什么问题

| 现状痛点 | SuitMe 的做法 |
|---|---|
| 单个 AI 助手只能聊天，干不了跨岗位的活 | 任务在一群职责分明的 Agent 之间路由、交接、互相评审 |
| AI 干活黑盒，不知道它干了什么、花了多少 | 每一步都有事件留痕、审计台账、成本账本，可回放可追责 |
| AI 自作主张替人做决定 | 提问链路 + 审批链 + 验收红线：**核可、放行、验收永远由原发起人确认** |
| 干完就忘，下次从零开始 | 打回记忆、团队记忆、知识库三层沉淀，经验复用 |
| 云端 SaaS 担心数据外泄 | 全本机部署：任务、知识、凭据不出你的电脑（外部模型调用显式配置、显式留痕） |

## 核心能力清单（当前全部可用）

### 1. 多 Agent 协作
- **13 个在编 Agent**，各有职责定义、生效范围与版本（组织级 Agent 注册表）
- **智能路由**：五个派活点统一经 Router，按业务域分层最多 2 跳，路由决策全程 Trace
- **任务交接**：跨职能转交带授权卡（Transfer）、验收标准起草方与承接人分离
- **服务网**：个人 Agent 与公共服务（可行性/起草/评审三档服务）按职责目录调用

### 2. 长程执行（autoloop 模式）
- **挂起零消耗**：等人拍板时进程退出，不烧 token；回答到达自动续跑
- **步数熔断**：单 run 步数上限，防失控循环
- **状态外置**：PostgreSQL 步进队列，进程崩溃可接棒，换机器可继续
- **到点唤醒复查**：任务可预约「X 时间后复查」，到点自动唤醒一轮复查（本轮新增）

### 3. 自动化入口（本轮新增）
- **定时调度器**：例行任务（如每日晨报、每周健康检查）按计划自动建任务进协作环
- **GitHub 监听**：轮询 + webhook 两种方式监听仓库的推送/议题/PR，事件自动转任务（验收不放行，合并走审批链）
- **钉钉/企微通道**：群机器人 webhook 出站通知（与飞书共享注意力预算），入站端点可选

### 4. 会话入口
- **飞书**（主通道）：发消息建任务、接续任务、回答问题、确认验收
- **Paperclip 工作台**（3100）：全中文的仪表盘、任务、代理、待办、审批、目标、预算界面
- **管理控制台**（4200）：只读运维视角 + 语义知识检索
- **CLI / MCP**：本机命令行与工具协议接入

### 5. 知识底座
- **知识空间**：按项目/主题组织，跨空间资料申请-授权-到期-撤权全链路
- **三层记忆**：会话记忆 → 团队记忆（打回沉淀）→ 知识库（验收后入库）
- **语义检索**：设备端词向量 + 本机 BM25 混合；Cognee 原生图谱管线（LLM 抽取走 DeepSeek，embedding 本机 fastembed）
- **组织图谱**：L2 组织关系确定性抽取（零模型调用）

### 6. 交付与验收
- **本机 Git 交付台**：代码成果进本机裸仓库，按确切提交与本机 CI 结果验收
- **验收合同**：开工前锁定逐项验收计划，独立评审者（不得是产出模型）逐项判定
- **一条链接报告**：验收报告可分享；打回只退未过项，且打回原因沉淀进记忆
- **视觉证据**：截图/录屏类证据做结构式绑定核对，不凭空判断图像内容

### 7. 治理与安全
- **RBAC**：人与 Agent 共用 casbin 策略，owner/admin/成员分级
- **注意力预算**：低价值通知被护栏抑制，人类必达消息（提问/验收/授权）永远送达
- **审计台账**：所有关键动作（授权、验收、定时触发、外发模型调用）留审计
- **凭据纪律**：API key、webhook、DSN 一律走环境变量或 0600 本机文件，绝不入库

## 界面一览

| 入口 | 地址（本机） | 用途 |
|---|---|---|
| Paperclip 工作台 | http://127.0.0.1:3100/ | 主界面：仪表盘、任务、代理、待办、审批、目标 |
| 管理控制台 | http://127.0.0.1:4200/ | 只读运维：服务状态、知识检索、系统体检 |
| Bridge API | http://127.0.0.1:4180/ | 所有能力的 HTTP 接口（workspace action 协议） |

## 上游开源复用（7 个 submodule，全部锁定提交）

| 上游 | 复用部分 |
|---|---|
| Paperclip | 工作台前端 + 任务调度核心 + 审批 |
| Super-agent | 飞书消息归一化、幂等回复、策略门控 |
| Autoloop | worker、执行适配器、进程与回执恢复 |
| Acceptance（LobeHub 设计语言） | 验收计划/判定/报告/打回记忆的方法论 |
| Cognee | 图谱存储、来源追踪、cognify 管线 |
| DeepSeek Harness | Agent 身份装配、提示词与工具限制 |
| Prime-agent | 会话参考与序列化工具 |

## 开始使用

```sh
git clone --recurse-submodules https://github.com/zhegong-996/suitme-collab.git
cd suitme-collab && npm install && npm run up
# 打开 http://127.0.0.1:3100/
```
