# 知识协作工作区

模式：Operate。扩展现有知识协作页面，继承 Paperclip 视觉系统。

- 我的工作：待授权、待采用、执行待核对和可验收的事项，附属任务、参与者、资料和期限，直接处理或跳到具体任务。
- 跨参与者任务：可搜索列表、活动/全部过滤、连续详情。资料与权限、交接、知识候选和审计围绕同一任务。
- 知识空间：可配置项目、主题或团队空间的列表导航、检索、结构化事实、正文和版本；选择条目即可带入新任务。
- 授权申请：集中查看待处理与历史，可进入任务，不复制第二份申请。
- 发起协作：写目标与验收条件，选择执行参与者和必要资料，选择 Agent 自动准备或建议模式。创建真实任务后由 Paperclip 执行。

Agent 默认只能自动准备访问申请、总结、待办、检查点和知识候选；授权、共享、参与者交接和最终验收仍由人决定。模型每轮只有当前参与者已获准且版本有效的材料，调用时不携带后台凭据；上下文变更后结果失效，不复用旧模型会话。原生子任务与运行记录提供查询、取消、失败和恢复。
