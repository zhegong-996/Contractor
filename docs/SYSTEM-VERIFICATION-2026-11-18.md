## 待修问题和边界

1. **发布检查会失败。** `sources.lock.json` 仍锁定原 Paperclip 目录中的 Badge、Button、Input，现用组件位于 `workbench/src/components`。主 CI 在后端回归之前执行来源审计。应核实三个替换组件的实际来源，再更新锁和声明。
2. **交付证据在前端展示不全。** 工单能显示 CI、部署状态和验收入口。后端新增的 `deliveryVerification` 已提供每项检查、模板版本和独立审查，且有 `recheck-delivery` 接口，工作台未接这些字段和重核动作。用户不能仅靠当前交付页判断卡在哪一项。
3. **渠道回执在前端展示不全。** 后端区分发送成功、等待、确认中和未确认。工作台工单详情未消费 `channelReturn`，用户看不到需要查证回执的状态。此问题独立于回执重放去重。
4. **前端共享包偏大。** Vite 报告导航相关共享产物约 679 kB，gzip 约 217 kB。窄屏布局用例通过，尚无实测弱网加载数据。
5. **积分属于业务额度，运行中控制取决于执行端。** 回归按实际消耗结算并封住后续派工。不能据此断言每个 CLI 都有统一的生成途中 Token 硬停。

本轮只写入报告、隔离测试记录及本地构建产物。没有修改业务代码、切换现有测试工作台、推送 GitHub、调整真实权限或外发飞书通知。
