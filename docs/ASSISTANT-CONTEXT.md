# 协作 Agent 与上下文工作区

2026-11-05。保留 Paperclip 原生任务、授权、运行、文档版本和审计。前端按“我的工作、跨岗位任务、知识空间、授权申请”组织；任务内的“进展、上下文、岗位交接、知识沉淀”共享同一任务。

## 人与 Agent

用户写目标与验收条件，选初始岗位。默认允许 Agent 自动查找岗位原有可读知识、为明确选入任务的其他岗位资料准备访问申请、归纳事实和缺口、制作可审阅工作稿、保存检查点与知识候选。授权、知识确认/采用、岗位责任交接和最终验收由人决定。

“仅给建议和草稿”模式保留模型结果，不自动写入检查点或知识候选。暂停、失败、正在取消、上下文失效均有真实状态，不以静态示例冒充模型结果。

模型由 Paperclip 原生私有子任务与 run 执行，不另建调度器。当前真实执行验证使用本机已登录的 Codex；Claude Code 复用 Autoloop 适配器路径，未在本轮真实启用。WorkBuddy、豆包等继续使用已有人工/MCP 接单方式，不能据此声称它们的自动 CLI 已验证。

## 上下文不是附件列表

| 层 | 内容与获取方式 |
|---|---|
| 目标与约束 | 原生任务需求、验收条件、明确补充要求、人工背景与约束 |
| 专业证据 | 当前岗位原有权限内的已确认知识，以及当前任务明确获准的跨岗位资料 |
| 工作状态 | 当前任务检查点、工作稿和人工修订；每条保留来源、修订和内容指纹 |
| 已有交付 | 人明确关联且当前岗位原生 ACL 可读的研发任务，含需求、飞书发起标识、PR、CI、预览版本和验收状态 |
| 讨论与决定 | 平台已经同步到原生任务的成员补充、系统回写与结构化决定，不把机器回复视作新的人类决定 |
| 缺口 | 缺事实、缺目标/约束、缺权限、版本未确认、暂不可用、正文只载入片段，分别处理 |

自动检索只在当前岗位已经可读的知识内进行，按目标和近期背景排序；跨岗位引用不授予权限。用户可以手动补充、关联、引用、移出和扩展读取。移出资料会关闭相应申请、结束本任务临时授权，并防止自动检索重新加入。

目前按权限内词项与目标/近期上下文排序检索，不冒充已部署向量检索。飞书范围是已同步任务需求、补充与来源标识；没有默认爬取全公司私有群聊或云文档。

## 来源、预算与失效

每轮保存原生 assistant-input 文档，包含实际上下文、输入清单和覆盖范围；运行记录保留其修订。每份输入绑定种类、原对象、修订、内容指纹和保留范围。正文按相关片段获取，保留实际字符/字节范围；事实字段、讨论条数和预算截断也有明确标记。模型不能把片段当成全文。

使用 DeepSeek Harness 的 TextRetainer/ItemRetainer 限制内容并保留 UTF-8 边界和精确遗漏事实。默认内容预算为192000字节；单份长资料、背景或讨论可扩展，最多两份。Agent 明确指出覆盖缺口时可自动触发这两次限额内扩展；不能用扩展绕过 ACL。

装配前、装配后、模型回传时重新核对真实输入。人工新增/编辑背景、原生编辑检查点、资料修订、授权或岗位变化都会使旧结果失效。只排除当前运行自己产生的检查点，防止自触发循环；下一轮可以读取此前工作稿。采用新知识时再次核对输入版本；历史记录未保存完整输入清单的，明确标为旧记录，不补造历史证明。

AI 引用必须使用本轮存在的来源 ID，原文必须是该资料片段的逐字子串。这个校验只证明出处，不证明归纳完整或业务判断正确。未确认的工作稿与任务笔记留在任务内，只有人明确采用的知识进入专业空间。

撤权后摘要与引用不再作为当前上下文返回；原生受限文档 grant 同步回收。任务结束会结束受限检查点、背景与候选的临时 grant。平台管理方保留私有审计档案；普通岗位不因模型运行而获得原生运行项目或其他岗位的访问权限。

## 代码复用

- Paperclip：控制台宿主、任务、项目、审批/grant、run、文档版本、Markdown 编辑器与导航。
- Agent Autoloop：原版 Codex/Claude 命令与回执解析；本阶段的 AI 整理使用同一执行适配边界。
- DeepSeek Super-agent：既有飞书接入与原处回复机制继续使用；只在需要人或有可用结果时提醒。
- DeepSeek Harness：直接导入 output-retention 和 session-reference 的 tag-safe JSON 序列化源码；借鉴分层上下文、真实输入覆盖与失效边界，未启动第二套 Harness 服务。
- Prime Agent：移植 CJK/多语检索分词和目标/近期背景权重；用原版 Python 函数生成测试基准，核对 TS 迁移结果。保留本地工作与跨任务知识的区别，未开启自动改写公司规则。
- 用户既有本体论原型：迁移引用逐字核验、生成期间输入变化即失效、撤回后隐藏旧引文的实现。没有复制 Alice 原包恢复业务代码。

固定版本和许可证见 THIRD_PARTY_NOTICES.md、docs/SOURCES.md。

## 启用

~~~sh
npm run setup:workspaces
npm run setup:assistant
npm run restart:bridge
npm run install:workspaces
npm test
npm run typecheck
npm run build:workspaces
~~~

当前仍是本机管理员与专业 Agent 身份；真实员工登录、飞书组织映射和团队部署尚需配置。外部 Agent 可通过 MCP 的 read_task_context、search_task_context、read_authorized_material、expand_authorized_context 获取当前合法上下文；没有自批权限工具。
