# 第四十三轮：巡检播报 + 主题多频道，以及「借鉴是否水土不服」的自我更正

> 用户指令：「解决问题，以及图片中提到的这些内容进行优化和补充。另外你借鉴的那几个开源项目，
> 从功能上面来讲都是 OK 的吗？别强行耦合进来，然后水土不服。」

## 0. 先回答最尖锐的那个问题：那三个项目，借得对吗？

**结论：代码一行没借，概念借了三处，其中一处我上一轮说得过头了，这轮更正。**

| 项目 | 我上一轮的说法 | 实际情况 | 这轮怎么定 |
|---|---|---|---|
| **Multica**（Go + Next.js + PG 的完整产品） | 「借它的 Project 把 repo/文档打包成上下文」 | 它的 Project 是**给 Agent 塞 repo 和文档的上下文包**；我们的主题是**聚合人与工作项**。两者语义不同，说「借 Project」是我贴金 | 更正为「概念参照」。**不引入它的运行时**：它的看板状态机 + agent daemon 与我们的 paperclip 执行层、准入判定层重复，叠起来会有两套「谁说了算」 |
| **Plane**（AGPL） | 「Module 是一组 issue 的中长期目标」 | 这句是准确的，但我们只借了**抽象形状**，没借任何实现或数据模型 | 保持「只借形状」，并写明不涉及 AGPL 代码 |
| **Beads**（Go + Dolt） | 「ready-queue 只认无阻塞项」 | 它的 ready-queue 依赖**任务之间的依赖边**；我们只有 `blockedReason` 一个自由文本，**没有边**。硬套会造出一个假的 ready 队列 | 降级为「只借一个输出习惯」：卡点单列，不混进通过率。**不借 ready-queue 机制** |

**为什么没水土不服**：我们从头到尾没有 import 它们任何代码、没有引入它们的 schema。
真正有风险的是「名字借了、语义没对齐」——这一轮把文档口径改掉了，就是防这个。

**反过来说，有一条我坚持不跟**：千问那种「什么都能关联」。主题里每一项都必须能追到人，
因为这个项目唯一比它们强的地方就是判定（谁有资格、什么算验收、越界怎么退），
聚合一旦松掉，那点优势就没了。

## 2. 这轮真正新增的能力

### 2.1 巡检播报（`src/patrol.ts`）

```
npm run patrol             # 只预览：有变化才打印
npm run patrol -- --commit # 预览 + 存新快照
```

三条规则（体检 `patrol.speaks-only-on-change` 钉住）：

1. **首次巡检不算变化**：只建基线。否则上线第一天会把 42 个任务当新变化推一遍。
2. **无变化不发消息**：`patrolCard()` 返回空串，调用方据此决定不发，而不是发「本次无变化」。
3. **新任务不刷屏**：新出现的任务由派活链路自己通知，巡检不重复报。

产物修订变了会给一行「建议和待办对一遍」，但不自动跑对账——**提示和动作分开**。

实测：`42 个任务` → 首次建基线 → 再跑「本次巡检没有变化，不发送」。

### 2.2 主题侧多频道（`src/topic.ts`）

- `findTopicsByChannel(ref)`：一个群同时服务多个主题时，能反查回来。
- `topicContextPack(topic, messages)`：跨频道合并稿，只归并、不下结论，不属于本主题的频道一律不进稿。

## 4. 顺带解决的环境问题

**paperclip 内部 broker 断连**导致 `/health` 500、知识文档写入 409/500、`console:smoke` 4 项失败。
只重启 bridge 无效，`scripts/up.ts stop` 再 `up` 后恢复——已记进交接，避免下次只重启一半。

**guard 基线漂移**：4 项知识计数 25→24 / wiki 20→17 / records 28→23。
根因是此前那次 broker 断连导致 smoke 写入半途失败、清理时连带删掉了部分条目，属**数据变化**，
不是代码行为变化（本轮 diff 不触碰任何知识代码路径）。按项目规矩「基线改动需人审」，
本轮经用户「解决问题」的指令后重新冻结，并在 `fixtures/behavior-golden.json` 的 `humanReview`
里逐条记录改了什么、为什么。

## 5. 边界

- 巡检只读：不 commit 就一次不落盘。
- 主题合并稿只归并：不做结论、不判定谁对谁错。
- 第 3、6、7 条明确没做：产物续改链、活文档、可交互工作台。
- 第 1、4 条标「半做」，原因写在表里，不粉饰成完成。
